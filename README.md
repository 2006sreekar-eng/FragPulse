FragPulse

FragPulse is a browser-based aim trainer game created using HTML, CSS, and JavaScript. The main idea of this project is to improve reaction speed and aiming accuracy in a fun and interactive way.

In this game, the user enters a username and starts the game. After a countdown, targets appear at random positions on the screen and the player has to click them as quickly as possible. The game tracks score, hits, misses, accuracy, and reaction time. After the game ends, the results are saved and displayed on a leaderboard.

Features

Username input Random target generation Countdown before game starts (3 → 2 → 1 → GO) Score tracking Hit and miss counter Accuracy calculation Average reaction time calculation Leaderboard system Reset leaderboard option Clear current game stats option Data saved using localStorage

languages Used

HTML CSS JavaScript

How to Run

Download the project files Open the folder in VS Code Open index.html using Live Server Enter username and start playing Future Improvements
